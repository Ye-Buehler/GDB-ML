# OpenNMT-py Transformer

This directory contains the OpenNMT-py implementation used by the project.

## Installation

From the repository root, install the package in editable mode:

```bash
pip install -e ./transformer
```

## Package

The main Python package is located in `transformer/onmt/`.

This project is based on [OpenNMT-py](https://github.com/reymond-group/OpenNMT-py).
